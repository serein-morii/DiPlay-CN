# DiPlay CN

本仓库基于上游 DiPlay `v0.2.21`。桌面名称为 **DiPlay CN**，包名为 `com.shihab.diplay.cn`，可与官方正式版并存。

[English](README.md) · [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md)

为兼容的比亚迪安卓车机提供有线及无线 CarPlay，采用 DiAuto 风格界面。

> 这些项目专注于比亚迪汽车。它们可能在其他品牌上运行，但其他品牌不在支持范围内，也没有增加支持或修复其品牌特定兼容性问题的计划。
>
> **测试车辆：2025 款比亚迪汉 DM-i，车机 DiLink 5.0。** 其他车型、其他车机系统不保证所有功能可用。请自行测试，或拉取源代码按本车修改。

## CN 优化了什么

每一版改动都记录在 **[CN 优化日志](docs/CN_OPTIMIZATIONS.md)**：什么时间、改了什么、为什么改。当前基于官方 `v0.2.21`。

- 自定义转向卡 CN 增强版：大小 30%–95%、透明度 20%–100% 滑块；昼夜玻璃跟随车机；卡片下方行程信息条（到达 · 时长 · 里程）；无线切换掉线不清卡。
- 应用内更新（`0.2.10-cn.8` 起）：关于 → 检查更新，直接下载安装下一版，覆盖升级、设置保留。四通道：Gitee（默认）/ GitHub / gh-proxy.com / ghproxy.net。
- 开机自启 · ADB 修复：部分固件拦截开机广播时，一键把 DiPlay 加入后台白名单。
- CarPlay 期间延时暂停车机蓝牙（可选，5/10/15/30 秒）：来电只走 CarPlay，配对不受影响。
- 仪表盘地图新增「更小」档（125% 码流）：内容更多更精细。
- 车机语言不支持时默认简体中文；AirPlay 已连接后跳过无线切换看门狗，避免误重连。
- DiLink 5 仪表全屏／小屏自动切换、自定义转向卡位置预览、连接阶段提示，以及可选的已选 iPhone 蓝牙重连自动连接。
- 自 `0.2.10-cn.4` 起固定签名密钥，新版本直接覆盖安装、设置保留。

## 0.2.21 — CN 同步版

- **音乐**：修正 0.2.20 中音乐落后于 iPhone 的问题；暂停、切歌不再延迟几秒，播放速度也不再忽快忽慢。
- **有线连接**：iPhone 收下开始请求却一直不打开 CarPlay 时，DiPlay 会自动重新连接；点“断开连接”后不再一直等待；已经自行恢复的连接不再被重试断开。
- **麦克风与音乐**：在没有安卓自带 Opus 编码器的车机上使用麦克风时，DiPlay 不再闪退；通话或短暂打断后，音乐会恢复播放。
- **无线连接与比亚迪车机**：无线 CarPlay 无法启动时会显示原因；CarPlay 结束后，DiPlay 会把仪表交还给原车；从 DiYou 桌面卡片打开时不再闪退；Android 10 以上的比亚迪车机可使用“隐藏比亚迪来电弹窗（实验性）”。
- **安装与语言**：官方 APK 支持 Android 7.0 起，并新增意大利语；CN 版维持 Android 7.1（API 25）起。
- **新选项（默认关闭）**：临时显示系统栏（5 秒）、黑色圆角遮罩、方向盘播放／暂停按钮、双击触发 Siri、导入车机热点详情（实验性）、桌面悬浮球（实验性）、车辆原厂音乐律动。
- **CN 功能继续保留**：四通道更新及已校验 APK 本地复用、完整分类下滑设置、DiLink 5 仪表全屏／小屏联动、自定义转向卡和独立包名。

[0.2.21 完整说明](docs/RELEASE-NOTES-0.2.21.md)包含贡献链接及功能限制；构建和验证信息见[验证记录](docs/VALIDATION.md)。Android 7.0–8.1 尚需实车验证，不宣称所有车型的连接、音频或 Siri 问题均已解决。可选功能请停车后测试。

### 请提供 0.2.21-cn.1 的新诊断报告

1. 更新到 **0.2.21-cn.1**，复现问题并记录发生时间。开机／自动启动问题发生后，可手动打开 DiPlay 导出。
2. 打开“**设置 → 诊断 → 保存诊断报告**”。Android 10+ 通常保存到 **Downloads/DiPlay**；Android 7.1–9 会请求存储权限并同样保存到该位置，也可点“选择保存位置”。如选择器或公共存储不可用，应用会使用专用外部或私有目录，并在确认中说明目的地。
3. 使用确认中的**查看报告／分享**；没有分享应用时，可在报告视图中选择并复制文本。检查 `.txt` 并删除隐私信息，再附到匹配的[现有 CN 问题](https://github.com/serein-morii/DiPlay-CN/issues)，或[新建问题](https://github.com/serein-morii/DiPlay-CN/issues/new)。报告不会自动上传，请勿公开热点密码或私有认证文件。
4. 注明车型／车机、DiLink/Android/完整固件版本、iPhone/iOS、USB／车机热点／Wi-Fi Direct／同一局域网、相关设置、复现步骤、预期与实际结果及故障时间。

[从源码构建](docs/BUILD.md)：主应用请选择 `mobile` 模块。`maphost` 是地图演示应用，构建步骤和 APK 路径见说明。

## 仪表显示「简易模式」怎么办

若使用 DiPlay 后仪表进入简易模式，先在设置中关闭「仪表盘歌曲」「CarPlay 地图上仪表盘」及「HUD 和仪表盘导航」，再重启车机或切换一次仪表主题。恢复后逐项开启，最后再尝试歌曲投屏。

历史记录：[0.2.17](docs/RELEASE-NOTES-0.2.17.md)、[0.2.16](docs/RELEASE-NOTES-0.2.16.md)、[0.2.15](docs/RELEASE-NOTES-0.2.15.md)、[0.2.14](docs/RELEASE-NOTES-0.2.14.md)、[0.2.13](docs/RELEASE-NOTES-0.2.13.md)、[0.2.12](docs/RELEASE-NOTES-0.2.12.md)、[0.2.11](docs/RELEASE-NOTES-0.2.11.md)、[安装与连接](docs/INSTALL.md)。

这是公开预览版，**未经 Apple 认证**。APK 使用从公开 Carlinkit 固件中提取的既有实验性配件身份，并非为 DiPlay 新签发的 MFi 身份；其中的私钥可被提取，未来 iOS 是否继续接受及其公开分发适用性尚未确定。配件身份不进入 Git；**CN Android 发布签名密钥已公开**，详见[签名限制](SECURITY.md)。普通源代码/CI 构建默认不配置配件身份。部分车机仍可能卡顿或无法应用图标大小设置。

标准导航小组件需要支持 Android 小组件的启动器；比亚迪内置主页不接受任意小组件。悬浮地图和嵌入地图需要启用“CarPlay 仪表地图”。应用及网站源代码包含英语、简体中文、繁体中文（台湾）、阿拉伯语、俄语、乌克兰语、西班牙语和日语。应用的香港／澳门及 Hant 选择使用台湾译文，不宣称提供独立地区翻译。[繁体中文说明](README.zh-TW.md)提供安装、设置、隐私和构建指南。源代码、构建说明及许可证随版本提供。
