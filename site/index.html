Your iPhone.
At home in your car.

Maps, music and conversations on your car display. DiPlay brings wired and wireless CarPlay to compatible Android head units, with the familiar DiAuto interface.

Download APK ↓Gitee (China) ↓How to install

No jailbreak, dongle, account or authentication server required.

Install on the car, not the iPhone. Android 7.1+ (API 25); Android 7.1–8.1 support is new and still needs vehicle testing. USB and wireless are available; wireless uses the car hotspot, Wi-Fi Direct or Existing Wi-Fi / Same LAN. Compatibility depends on the head unit, firmware and iOS.

Field-tested on a 2025 BYD Han DM-i with DiLink 5.0. Other models and head-unit systems are not guaranteed; test on your own car or adapt the source.

Install on your car

  1. While parked, download the APK and install it using the method supported by your head unit.
  2. Open DiPlay and allow the requested Bluetooth, Wi-Fi/location and microphone permissions.
  3. Turn on the car’s built-in hotspot (5 GHz if available). In Settings → Connection → Open connection setup, select Built-in car hotspot and save its exact name and password. Keep phone Wi-Fi and Bluetooth on, pair with the car, then tap Connect phone and accept the phone prompts.
  4. For wired use, connect a USB data cable and choose Connect with USB. Approve any USB, Trust or local VPN prompts.

ADB is not required for everyday use. APK installation options depend on the car. No manual MAC address entry.

Before you try it

A public preview, not an Apple-certified product. Authentication uses an experimental accessory identity recovered from public firmware; future acceptance is not guaranteed. Some head units still show stuttering or ignore icon-size changes. Start with 30 fps and HEVC off; try a lower resolution if needed.

Updates & signing

Install over the previous public release to retain settings; the public signing key is unchanged. Test builds use a separate app package.

DiPlay CN APKs are signed with one stable key since 0.2.10-cn.4: install over the previous CN build to keep settings. About → Check for updates downloads and installs the next CN build in place (first use asks once for the install-unknown-apps permission).

Please send fresh reports from 0.2.15

1. Update to 0.2.15, reproduce the issue and note the failure time. 2. Open Settings → Diagnostics → Save diagnostic report. Android 10+ normally saves to Downloads/DiPlay; Android 7.1–9 uses a file picker. If storage or the picker is unavailable, follow the fallback confirmation and use View/Share. 3.
