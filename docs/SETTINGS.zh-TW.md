# 設定與疑難排解

[繁體中文首頁](../README.zh-TW.md) · [安裝與連線](INSTALL.zh-TW.md) · [隱私權與診斷](PRIVACY.zh-TW.md)

## 設定分類

| 分類 | 用途 |
| --- | --- |
| 概覽 | 連線狀態、分類入口、常用快速設定及設定精靈 |
| 連線 | iPhone 選擇、USB／無線、權限、自動連線與隨車啟動 |
| 顯示 | 解析度、影格率、圖示與文字大小、日夜外觀、畫面調整及介面大小 |
| 音訊 | 媒體／導航音訊串流、音樂緩衝 |
| 導航 | 位置回報與相容韌體的比亞迪導航提示 |
| 車輛 | 駕駛側、方向盤按鍵、車輛按鈕及 CarPlay 手勢 |
| 診斷 | 連線證據與診斷報告 |
| 進階 | 實驗性或特定韌體的顯示、影片、音訊與車輛資料功能 |
| 語言 | 應用程式語言與跟隨系統 |
| 關於 | 版本、更新、設定備份及專案資訊 |

請依你要完成的操作選擇分類。標有 **（實驗性）** 的功能可能影響聲音、畫面或連線，預設通常關閉；先在停車時測試。

## 儲存與重新連線

- **套用並重新連線**：確認後套用，並重新建立正在執行的 CarPlay 連線。
- **儲存**／**已儲存，將在下次連線時生效**：供下次連線使用。
- **立即重新連線**：設定需要重新連線時，依畫面提示主動重新連線。
- 只選擇新值不等於套用；取消會保留舊值。快速選單尚有未套用變更時，離開會要求確認。

**介面大小**改變 DiPlay 自身的控制項和文字，與 CarPlay 的圖示／文字大小不同。DiPlay 本身的外觀與 CarPlay 日夜模式也分開設定。

## 常見問題

| 現象 | 建議檢查 |
| --- | --- |
| 無線連線沒有開始 | 確認權限、iPhone 配對、所選手機與連線模式，並關閉其他投影應用程式。車載熱點須開啟且名稱／密碼正確。 |
| iPhone 沒有自動加入熱點 | 確認自動加入設定，測試手動加入是否能連線並記錄結果。若 Android 藍牙無法實際連到 iPhone，改測 USB。 |
| Wi-Fi Direct 卡頓 | 測試車載熱點；車機的 Wi-Fi 掃描可能中斷封包，增加緩衝不一定能修復。 |
| 畫面不流暢或凍結 | 先用 30 fps、預設圖示大小、較低解析度及 H.264；關閉 HEVC 和實驗性解碼選項，再匯出報告。 |
| 圖示或文字大小沒有改變 | 確認已套用並重新連線；部分 iPhone／車機組合仍可能忽略請求的配置。 |
| 音樂或導航沒有聲音 | 檢查「音訊」的媒體／導航串流，逐一試聽。若啟用「音訊焦點」後失去聲音，依說明關閉並重新連線。 |
| 來電後音樂一直靜音 | 車機可能沒有恢復音訊焦點。在「進階」的音訊焦點設定中關閉「暫時失去音訊焦點時將媒體靜音」，重新連線後測試。 |
| USB 只能充電 | 換用資料傳輸線及 USB 資料連接埠，確認 USB、iPhone 信任及所需 VPN 權限。 |
| USB 反覆斷線 | 在 USB 設定中調低 iPhone 充電等級，並測試另一條資料傳輸線；重現後保留診斷報告。 |
| HUD／儀表板沒有導航 | 確認韌體及相關功能的支援條件；不同 DiLink 版本不能直接共用所有設定。 |
| 更新無法安裝 | 確認 APK 的套件名稱與簽章相符。不要在未備份所需資料前直接解除安裝。 |

舊 Wi-Fi Direct 群組阻擋連線時，先關閉其他投影應用程式，再使用 **設定 → 連線 → 無線連線說明 → 重設 CarPlay Wi-Fi**；移除無法識別的群組前，DiPlay 會要求確認。

通話、Siri、背景重新連線及長途使用仍需要更多實車證據。上述步驟是排查方法，不代表每種車型的問題都已修正。深入限制見[英文相容性指南](COMPATIBILITY.md)與[0.2.22 版本說明](RELEASE-NOTES-0.2.22.md)。

## 在手機上備份或還原

開啟 **設定 → 關於 → 在手機上備份或還原**，讓手機與車機位於同一網路，再用手機掃描 QR 碼。

- **匯出設定**將目前設定儲存為檔案。
- **選擇檔案並匯入**載入既有 DiPlay 設定檔；缺少的設定項目保持目前值。
- 離開備份頁面後服務會停止。此功能是設定備份，不應視為完整應用程式或認證／配對資料的備份。

## 匯出診斷報告與回報問題

1. 使用本文件對應的 **0.2.22** 重現問題，記錄發生時間。開機／自動啟動問題可在發生後手動開啟 DiPlay 匯出。
2. 開啟 **設定 → 診斷 → 儲存診斷報告**。
3. Android 10 以上通常存至 `Download/DiPlay`；Android 7.0–9 會要求儲存權限。也可以使用 **選擇儲存位置**。
4. 若公共儲存空間或檔案選擇器不可用，應用程式使用專用外部或私有目錄；確認訊息會顯示實際路徑。使用 **檢視報告**／**分享診斷報告**；沒有分享應用程式時，可在報告檢視中選取並複製文字。
5. 檢查 TXT，移除不適合公開的資訊，再附到[相關 CN 問題](https://github.com/serein-morii/DiPlay-CN/issues)或[建立新問題](https://github.com/serein-morii/DiPlay-CN/issues/new)。

請附上車型與車機型號、完整韌體／Android／DiLink、iPhone／iOS、DiPlay 版本、連線方式（USB／車載熱點／Wi-Fi Direct／同一區域網路）、相關設定、重現步驟、預期與實際結果，以及故障時間。

報告不會自動上傳。請勿公開熱點密碼、私密金鑰或私人認證檔案，詳見[隱私權說明](PRIVACY.zh-TW.md)。
