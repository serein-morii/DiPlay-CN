# DiPlay CN {{VERSION}}

基于官方 DiPlay v0.2.22。包名 `com.shihab.diplay.cn`，可与官方版并存。覆盖安装上一版 CN 即可保留设置。

**测试范围：** 实车验证车辆为 **2025 款比亚迪汉 DM-i，车机 DiLink 5.0**。其他车型、其他车机系统不保证所有功能可用；请自行测试，或拉取源代码按本车修改。

**下载**

- APK：本 Release 附带的 `DiPlay-cn-v{{VERSION}}.apk`（Gitee 同步：https://gitee.com/oneeyear/DiPlay-CN/releases/latest）
- 完整优化记录：[docs/CN_OPTIMIZATIONS.md](https://github.com/serein-morii/DiPlay-CN/blob/main/docs/CN_OPTIMIZATIONS.md)

**签名风险：**为保留旧版 CN 的覆盖升级能力，当前 Android 发布签名密钥已公开；“签名一致”不能证明 APK 来自本项目。只从本仓库列出的 GitHub/Gitee 发布页下载，勿安装转发或未知镜像的 APK。详情：[SECURITY.md](https://github.com/serein-morii/DiPlay-CN/blob/main/SECURITY.md)。

**本版更新**

- **合并官方 v0.2.22 全部更新**：修复比亚迪 DiLink 3.0/4.0 车机热点无线连接卡在“正在打开 CarPlay”；Wi-Fi 音乐恢复 iPhone 原始速度（0.2.21 的先快后卡不再出现）；USB 下微信语音/语音备忘录/听写能录到声音；重新插线后有线 CarPlay 首次即连；连接失败时画面会说明原因。官方还合并了一大批安全加固（更新下载校验、诊断报告、备份服务等）与新选项（默认关闭）：桌面卡片保留 CarPlay、导航提示音请求音频焦点、按通话原始采样率通话、DiLink 3.0 全屏仪表地图、腾势 N9 仪表地图。官方新增韩语和土耳其语；CN 版维持 Android 7.1（API 25）起。
- **更新器安全加固同步**：官方 0.2.22 的更新下载 URL 白名单校验已并入 CN 更新器（放行 github.com 与 gitee.com，HTTPS、无端口、无用户信息），四通道更新不受影响。
- 保留 CN 四通道（Gitee、GitHub、两个镜像）更新与既有全部 CN 功能（分类式下滑设置、仪表全屏／小屏联动、自定义转向卡、只读兼容性探测等）。
- **转向卡新增「下下个路口」预览（仪表卡 + 桌面小部件卡）**：主转向右侧新增紧凑小区——细分隔线 + 下下个路口的转向小图标（环岛带出口编号徽章）+「然后」字样。iPhone 协议不发送下下个路口的距离，与 CarPlay 原生横幅和高德的做法一致只显示图标；卡片过窄或第二路口详情未到时自动隐藏，不挤占主信息。
- **新增（实验性，默认关闭）：音乐走车机蓝牙，导航仍走 CarPlay**。开启后 DiPlay 不再向 iPhone 声明音乐音频流，音乐经由 iPhone 与车机的蓝牙连接（A2DP）播放，导航语音、提示音、通话和 Siri 仍走 CarPlay 音频。需要 iPhone 与车机保持蓝牙配对并将车机音源选为蓝牙。此模式在部分 iOS 版本上的回落行为需实车验证：如果音乐暂停或从 iPhone 扬声器播放，关闭开关并重连 CarPlay 即恢复。已有实验设置「CarPlay 音频全走车机蓝牙」保持不变，两者同时开启时以全蓝牙模式为准。
- **随 cn.2 保留**：转向侧影像自研实现（Han DM-i 校准参数开箱默认、校准采集、通道扫查与任意方向翻转）——所有侧影像开关与设置均标注实验性、默认关闭，仅限停车配置测试。
- 本版合并官方 0.2.22 与上述 CN 新功能均未实车验证，其他车型和固件仍需反馈。

请安装在车机上，不要安装在 iPhone 上。车机必须允许安装 APK。
