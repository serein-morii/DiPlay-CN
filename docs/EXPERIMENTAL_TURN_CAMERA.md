# DiPlay 转向影像与仪表联动（实验性）

这是供停车调试、收集反馈的实验构建，不是稳定版，不是已经通过本车验证的驾驶辅助系统。默认关闭，不会自动探测取流、申请相机权限、启动原车 AVM、点击原车界面或写入车辆参数。

## 已接通的软件功能

- 左转信号选择左侧摄像头，右转信号选择右侧摄像头；显示真实首帧后才显示画面。
- 画面叠加在 **DiPlay 已有仪表地图窗口** 内，不替换原车仪表、不另建全屏投屏路由。需要现有仪表地图已成功显示且投屏主程序在前台。
- 左右独立的窗口上下/左右位置、宽高；图像上下/左右偏移、缩放、90°旋转、镜像/翻转、完整显示/裁剪填满。
- 未知信号、双闪、倒车、OEM 360 占用、过期帧、失去前台或窗口销毁时隐藏并关闭；关闭无法确认则停止实验，重启应用前不再打开。
- 导航/车速优先，音乐封面让位。只识别 DiPlay 自己的覆盖层，不声称能识别所有原车告警。
- 只读兼容性报告、Camera2 静态参数、固件绑定及保存报告；配置恢复前预览/确认。

## 使用入口与首次配置

1. **诊断 → 转向影像只读探测**：复制报告。Camera2 的 `back` 不等于车辆左/右，类存在也不证明有可用画面。
2. **高级 → 转向影像（实验性） → 摄像头调校**：分别输入确认过的左右 AVM 编号并调整模拟图。这里仅模拟，不会打开摄像头。Camera2 目前只支持信息读取/草稿，真实取流后端为 Vendor AVMCamera。
3. **信号与取流配置（实验性） · JSON**：填入本车实际值。`null` 是未知，不是 0。保存任何一份配置都会关闭实验，需要重新确认启用。
4. 完成本车参数确认后，手动启用 **仪表自动转向影像（实验性）**，返回现有仪表投屏。没有有效配置时开关不能启用；没有可用仪表路由时不会打开相机。

JSON 字段：

| 字段 | 含义 |
| --- | --- |
| `turnOff/turnLeft/turnRight` | `getTurnLightState()` 的关闭/左/右实际编码（互不相同） |
| `hazardOff/hazardOn` | `getDoubleFlashLightState()` 的实际编码 |
| `reverseOff/reverseOn` | `getReversingLightState()` 的实际编码 |
| `oemClass/oemGetter/oemIdle/oemActive` | 本车 OEM 360 空闲/占用的确认来源；限定 `android.hardware.bydauto.*` 下无参 `int` 只读 getter，不调用 setter |
| `leftChannel/rightChannel` | Vendor AVMCamera 的预览通道，不能把其他车的值当默认值 |
| `leftWidth/leftHeight/rightWidth/rightHeight` | 实际支持的缓冲尺寸，1–4096 |
| `timestampTimebase` | 确认 producer 时基后选 `ELAPSED_REALTIME_NANOS` 或 `MONOTONIC_NANOS`；不能把接收时间当拍摄时间 |
| `safeArea` | 已有仪表地图内部归一化 `[left,top,right,bottom]`，不得覆盖原车关键仪表 |
| `safeAreaConfirmed/latchedSignalConfirmed` | 只有确认安全区域、转向 getter 表示持续拨杆而非闪烁脉冲后才填 `true` |

**尚未取得本车左右 AVM 编号、转向值、OEM 360 空闲语义、帧时基及安全区域的完整证据。** 安装这个包不等于上述数据已确认。默认模板不能启用真实取流；不能复制别的车型参数、把未知 OEM 状态写成“空闲”来绕过保护。此包没有自动扫描隐藏摄像头，也没有接管原车倒车/360。

## 安装与反馈

包名仍为 `com.shihab.diplay.cn`，保留现有 CN 签名，版本 `0.2.20-cn.1-experimental.1` / code 117。同版本号可覆盖安装；如果设备已装更高 versionCode，不要卸载/清除现有数据强行降级。实验版与稳定版共用应用数据，请先导出设置；实验启用状态和车型参数不进入可移植备份。

仅在停车且不需要倒车/360时配置。不要在驾驶中操作，不要依赖实验画面判断路况。出现黑屏/画面错误/原车影像异常时先关闭实验并重启应用，保留原车功能优先。反馈固件、脱敏报告、左右配置、转向/双闪/倒车/OEM占用时的表现和仪表截图；不需要提供账号或密钥。

两站附件应为 **同一个 APK**，请与同名 `.sha256` 校验。GitHub 标记为 prerelease，Gitee 标题明确实验性；不更新稳定 main，不替换稳定 Release，不声明实车通过。
