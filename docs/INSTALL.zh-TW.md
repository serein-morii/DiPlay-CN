# 安裝與連線

[繁體中文首頁](../README.zh-TW.md) · [設定與疑難排解](SETTINGS.zh-TW.md) · [英文安裝指南](INSTALL.md)

## 安裝前準備

1. 停車後，從[DiPlay CN 發布頁](https://github.com/serein-morii/DiPlay-CN/releases/latest)或 [Gitee 國內下載頁](https://gitee.com/oneeyear/DiPlay-CN/releases/latest)下載 APK。此版本需要 Android 7.1 以上（API 25+）；Android 7.1–8.1 尚待實車驗證。
2. 依車機支援的方式安裝在 **Android 車機**，不要安裝在 iPhone。安裝 APK 的限制由車機韌體決定。
3. 更新既有安裝時，使用相同應用程式套件／版本類型與相符的簽章。這樣才能保留設定和配對資料；不同簽章無法直接覆蓋安裝。解除安裝會移除應用程式私有資料。
4. 開啟 DiPlay，依使用功能授予藍牙／附近的裝置、Wi-Fi／位置資訊及麥克風權限；通知權限用於連線控制。較舊 Android 的無線連線需要位置權限。
5. 關閉其他手機投影應用程式。首次啟動的 **設定精靈** 可以略過，也可從設定重新開啟；其中車型標籤不代表完整相容性保證。

切換語言：**設定 → 語言 → 應用程式語言 → 繁體中文 → 套用**。語言頁也提供 **跟隨系統**。

## 無線：車載熱點

車載熱點是預設連線方式。

1. 在車機系統設定中開啟內建熱點，若可選，優先使用 5 GHz。
2. 在 DiPlay 開啟 **設定 → 連線 → 開啟連線設定**，選擇 **車載熱點**。
3. 準確填寫熱點名稱與密碼並儲存。
4. 保持 iPhone 的藍牙和 Wi-Fi 開啟，與車機配對；必要時在 DiPlay 選擇要使用的 iPhone。
5. 點選 **連線手機**，接受 iPhone 上的 CarPlay 提示。

相容韌體可透過藍牙握手傳送熱點資訊，核心 CarPlay 不需要 ADB。如果 iPhone 沒有自動加入，先確認該熱點的「自動加入」，再測試手動加入是否能開始 CarPlay，並將結果記錄在診斷報告中。不要直接假設密碼或 CarPlay 傳輸本身失效。

**自動啟動車載熱點**是另外的選用設定，預設關閉，需要相容比亞迪韌體及已授權的本機 ADB。它不等同於「開啟 DiPlay 時連線」或隨車啟動；請依各選項說明個別設定。

## 無線：Wi-Fi Direct

在 **開啟連線設定** 選擇 **Wi-Fi Direct**，保持車機 Wi-Fi、藍牙及 iPhone Wi-Fi 開啟，再連線。

- Android 7.0–9 依賴舊版韌體 API，使用系統產生的群組憑證，無法讀回實際協商頻率。
- Android 10 以上保留實際群組頻率驗證。能加入 5 GHz 網路不代表車機可建立 5 GHz 群組。
- 自動模式依可用頻道與韌體嘗試連線，不保證頻段或效能；限制頻段的自動選項及手動頻道也取決於硬體支援。
- 變更首選頻道會儲存供下次連線使用。現有工作階段不會因單純選擇而立即中斷；可依提示重新連線。

若車機反覆掃描 Wi-Fi 導致聲音或畫面卡頓，先測試車載熱點。舊版的頻道設定、群組清理及持久設定限制見[英文說明](ANDROID9_WIFI_DIRECT.md)。

## 無線：現有 Wi-Fi／同一區域網路

1. 在車機與 iPhone 的系統設定中，將兩者連到同一台外部路由器或隨身 Wi-Fi。
2. 關閉路由器的用戶端隔離；保持藍牙開啟。
3. 在 DiPlay 的 **開啟連線設定** 選擇 **現有 Wi-Fi / 同一區域網路**，儲存網路資訊，再連線。

DiPlay 不會代替你加入外部網路或變更預設路由，也不會在此模式建立熱點。詳細條件與驗證紀錄見[英文指南](EXISTING_WIFI.md)。

## 有線：USB

1. 使用支援資料傳輸的 USB 線，連接車機的 **USB 資料連接埠**。只有充電功能的連接埠或線材無法使用。
2. 點選 **透過 USB 連線**。
3. 出現提示時，允許 USB 存取，在 iPhone 上確認信任／CarPlay，並允許所需的本機 VPN。

本機 VPN 用於 USB 網路連線，不是遠端上網 VPN 服務。若反覆斷線並重新連線，可在 **設定 → 連線** 的 USB 設定中調低 iPhone 充電等級，再測試；充電速度也會降低。

## 連線後

先使用預設圖示大小、30 fps，並在 **設定 → 進階 → 影片與音訊** 保持 HEVC 關閉。較慢車機可嘗試 80% 或 60% 解析度。

部分設定即時生效，部分在下次連線生效。正在連線時，顯示調整使用 **套用並重新連線**；只選擇新值尚未套用。尚未連線時，儲存後供下次連線使用。請以各控制項的說明為準。

無法連線時，請參考[疑難排解與報告匯出](SETTINGS.zh-TW.md)。涉及個別車型的 HUD／儀表板整合，另見[比亞迪導航英文指南](BYD_NAVIGATION.md)。
