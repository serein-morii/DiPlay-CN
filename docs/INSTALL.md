# Install and connect

1. Park the car. For DiPlay CN, download the latest APK from [GitHub](https://github.com/serein-morii/DiPlay-CN/releases/latest) or [Gitee](https://gitee.com/oneeyear/DiPlay-CN/releases/latest). CN field testing is on a **2025 BYD Han DM-i with DiLink 5.0**; other models and head-unit systems are not guaranteed. Android 7.1+ (API 25+) is supported in code, but Android 7.1–8.1 still needs vehicle testing. The CN signing key is public; see [SECURITY.md](../SECURITY.md).
2. Install on the Android head unit using its supported APK installation method. Do not install on the iPhone. Use the same package/variant and a matching signing certificate for an in-place update that preserves settings and pairing records. Release-specific build and signing checks are recorded in [validation](VALIDATION.md); do not infer update compatibility from the filename.
3. Open DiPlay. Grant the permissions requested for the features you use: Bluetooth/Nearby devices, Wi-Fi/Location on older Android, and microphone for Siri/calls. Allow notifications for connection controls.
4. Close other phone-projection apps before connecting.

## Wireless

Built-in car hotspot is the default. Open **Settings → Connection → Connection setup → Built-in car hotspot**, turn on the car hotspot at 5 GHz if available, and save its exact name and password. Keep Bluetooth and Wi-Fi enabled on the iPhone, pair it with the car, then tap **Connect phone**. On compatible firmware, the Bluetooth handshake supplies hotspot credentials for automatic joining; core CarPlay does not require ADB. If the iPhone does not join automatically, record whether manual joining starts CarPlay and see the separately confirmed [experimental join repair](WIRELESS_HOTSPOT_JOIN.md). **Choose iPhone** changes the selected paired device. See [the setup guide](CONNECTION_SETUP.md).

Wi-Fi Direct is an alternative when the head unit implements the needed firmware APIs. Android 7.1–9 uses generated group credentials and cannot verify the requested frequency; Android 10+ retains negotiated-frequency verification. Legacy pinning/cleanup limits are in [Android 9 Wi-Fi Direct](ANDROID9_WIFI_DIRECT.md). **Existing Wi-Fi / Same LAN** connects through an external router or portable Wi-Fi: connect the car and iPhone to the same network, disable router client isolation, and save that network under **Settings → Connection → Connection setup**. Keep Bluetooth enabled. DiPlay does not join the network or change the default route for you; see [Same LAN setup](EXISTING_WIFI.md). The Local hotspot option has been removed; existing selections migrate to built-in hotspot. USB remains available.

In **Settings → Connection → Connection setup → Wi-Fi Direct → Preferred channel**, Auto keeps automatic selection: beside a 5 GHz station it tries eligible saved/aligned channels and explicit 2.4 GHz before other 5 GHz/system-default fallbacks. It does not guarantee a band. **Auto · 5 GHz** and **Auto · 2.4 GHz** stay inside that band and let the car pick the channel; if the car cannot use the band, startup stops with a message instead of switching. You may also save a supported 2.4/5 GHz channel for the next connection; an active session continues until reconnect. If the radio rejects it or creates a different channel, choose Auto or another channel and reconnect. Regional/radio support still applies, and channel choice does not establish stutter as fixed.

Optional automatic built-in-hotspot startup under **Settings → Connection** is off by default. On supported BYD firmware, explicitly enabling it verifies permissions for DiPlay's own package through already-authorized local ADB. It preserves the car's saved hotspot name/password; boot-open and connect-on-open are separate settings. The ADB fallback requires a reachable, already-authorized connection on each request and a firmware-advertised Wi-Fi tethering command; it reports success only after observing hotspot readiness. This does not establish support on every DiLink version. See [connection setup](CONNECTION_SETUP.md).

## USB

Connect the iPhone to a USB **data** port with a data-capable cable and choose **Connect with USB**. Approve USB access, Trust/CarPlay and the local VPN permission if requested. The local VPN carries the USB network link; it is not an internet VPN service. Charge-only ports/cables cannot work. If wired CarPlay drops every few seconds and the iPhone reconnects by itself, try **Settings → Connection → USB connection → iPhone charging → Reduced**, then **Low**; the iPhone then charges more slowly.

## Settings

Swipe down with the configured finger count in CarPlay to open DiPlay CN settings, or return to the home screen. Choose two, three or four fingers under **Settings → Vehicle → CarPlay controls**; three remains the default. CN checks for updates through its own four-channel updater (Gitee default) under **About → Check for updates**. Icon/text size, resolution and frame rate use **Apply and reconnect** during an active session. A selection alone does not apply; Cancel preserves the old setting. When disconnected, **Save** applies to the next connection. Follow each setting's description: some apply live, while others show **Reconnect now** and take effect at the next connection.

**Settings → Display** contains icon/text size, resolution, frame rate, day/night appearance, picture adjustments, dock position, system bars and **Interface size**. Interface size changes DiPlay's own controls, not CarPlay's picture. Start with 30 fps and Default icon/text size; leave **Efficient video (HEVC)** off under **Settings → Advanced → Video and audio**. Try 80% or 60% resolution for a slower head unit. Some iPhone/head-unit combinations still ignore icon/text scaling.

**Settings → Audio** contains media/navigation audio routing and the music-buffer choice. **Settings → Navigation** contains location reporting and the BYD navigation card on supported head units. **Settings → Vehicle** contains CarPlay gestures, wheel keys and car-button customization. Connection setup, automatic connection and permissions are under **Settings → Connection**; reports are under **Settings → Diagnostics**.

To map a spare steering-wheel button to CarPlay music play/pause (#815), open **Settings → Vehicle → Wheel keys**, enable **Play/pause key on the wheel**, then tap **Assign: Play/pause** and press the physical key. A configured key can be learned while DiPlay's settings screen is visible; vehicle-reserved keys need the optional wheel-key accessibility service (which can also work with CarPlay in the background). The remap is disabled by default, does not replace Siri/map-zoom/joystick key assignments and does not take over keys while a call is active or CarPlay is disconnected. **Fire TV, Google TV, Android TV and other HID remotes keep their existing D-pad, OK/Select, Back, Menu, Home, volume, assistant and dedicated media-button actions.** These standard or OEM-reserved codes cannot be reassigned to play/pause, including previously saved assignments; media controls continue to use the existing Android MediaSession route. Spare keys can still be assigned. This is Android-key compatibility, not a promise that every proprietary TV remote can pair with every head unit. Some OEM firmware intercepts keys before DiPlay can see them; when the key never appears in the diagnostic report, DiPlay cannot remap it without a firmware-specific integration.

Vehicle-data mode and battery/wheel-speed/parked-video controls are under **Settings → Advanced → Advanced vehicle data**. Battery reporting, wheel-speed reporting and parked-video controls are off by default. Default DiLink 5.0 mode remains the default. Legacy mode is optional, uses bounded read-only detection and needs authorized network ADB; it exposes only confirmed fields. Review any prompt to replace previously saved fields. This does not enable ADB, write vehicle settings or establish support for every older head unit.


Optional square-canvas rotation, split-screen areas and the side panel are under **Settings → Advanced → Display (experimental)** and are off by default. Larger canvases increase decoder/GPU work. Dock position remains under **Settings → Display**.

**Smooth video (experimental)**, **Buffered music (experimental)**, **Call echo cancellation (experimental)** and **Clearer call voices (experimental)** are under **Settings → Advanced → Video and audio** and are off by default. Smooth video can add touch-response delay and makes picture adjustments unavailable. Changing Smooth video or Buffered music reconnects an active session; call echo cancellation and voice filtering apply at the next connection. Buffered music accepts AAC-LC from supporting apps, not lossless audio. **Low-latency decoding (experimental)** and **Direct video output (experimental)** in the same card are also off by default. Low-latency decoding applies at the next connection; Direct video output reconnects CarPlay and makes picture adjustments unavailable. Turn either off if the picture shows artifacts or freezes. **Settings → Diagnostics → FPS counter** shows frames shown and received per second and the decode time.

Independent experimental **CarPlay call keys** and **CarPlay calls on the dashboard** remain off by default. They appear under **Settings → Navigation → BYD navigation**, or under **Settings → Advanced → Advanced vehicle data** when the BYD navigation card is unavailable. The dashboard card needs authorized ADB and target firmware. Review [0.2.19 limits](RELEASE-NOTES-0.2.19.md) before opting in.

The app includes eleven languages, including Italian, Japanese, Korean, Turkish and Traditional Chinese (Taiwan); the website has eight. Android 13+ app-language selection is synchronized with Android settings; Android 7.0–12 retain a saved context override. Hong Kong/Macao and Hant use the Taiwan app translation, not separate regional editions. See the [Traditional Chinese installation guide](INSTALL.zh-TW.md).

## Connection recovery and reports

If the head unit's wallpaper shows through CarPlay's rounded picture corners (#635), open the in-CarPlay settings menu and choose **Safe area → Black rounded corners**. The default is **Off**. A manual 12–48 dp radius previews immediately; pick the smallest radius that covers the wallpaper. **iPhone mask (experimental)** instead negotiates CarPlay's `cornerMasks` feature at the **next connection**, accepts the iPhone's `topLeftCornerMask` grayscale PNG, and mirrors its per-pixel coverage to all four corners. This is intended to reproduce the iPhone's actual contour rather than guess a circular radius. The feature is **unverified on a real DiPlay head unit** and depends on iOS offering a mask. It drops the main display's safe-area declaration (required by iOS for this feature), which may change UI placement. If the mask is absent or invalid, the app retains a local 24 dp approximation instead. Both modes fill the corners black above TextureView or SurfaceView output without intercepting touches. Save the setting and reconnect to apply the native mode; turn it Off if the picture or layout is wrong. **Square corners, no safe area** remains the established alternative for a rectangular picture.

If reinstalling left an old group, close other projection apps, then use **Settings → Connection → Wireless connection help → Reset CarPlay Wi-Fi**. DiPlay asks before removing an unrecognized Wi-Fi Direct group. Updating in place is preferable to uninstalling.

Please reproduce unresolved problems on **0.2.22-cn.1** and export a fresh report, even if you already sent older logs. Capture from the first connection attempt through the failure; for boot/auto-start problems, reboot and then open DiPlay manually to export. Use **Settings → Diagnostics → Save diagnostic report**. Android 10+ normally saves to **Downloads/DiPlay**; Android 7.1–9 asks for storage access and saves there too. **Choose save location** is also available. If the picker or Downloads storage is unavailable, the fallback TXT file is saved in app-specific external storage; the confirmation shows its exact path. If external storage is also unavailable, DiPlay saves the report privately. Both fallbacks offer **View report** and **Share**; select/copy text in the report view when no sharing app is available. Review the `.txt` file, then attach it to your existing [CN issue](https://github.com/serein-morii/DiPlay-CN/issues) or [create a new issue](https://github.com/serein-morii/DiPlay-CN/issues/new), with car/head-unit model, exact DiLink/Android/firmware versions, iPhone/iOS, connection backend (USB, built-in hotspot, Wi-Fi Direct or Same LAN), relevant settings, expected/actual behavior, reproduction steps and approximate failure time. Never include your hotspot password. Nothing is uploaded automatically.

The additional wireless/media/theme/own-app-exit records help identify the failing stage; they do not establish Qin Plus startup, Wi-Fi Direct stutter, Siri, iOS 15 or day/night firmware reports as resolved. See [0.2.22 release notes](RELEASE-NOTES-0.2.22.md).

APK installation restrictions are controlled by your car's firmware. ADB is optional if your car supports it, not an app runtime requirement:

```sh
adb install -r DiPlay-cn-v0.2.22-cn.1.apk
```

Only use a trusted computer. A different signing certificate cannot update this build; do not uninstall until you have saved any reports you need.
