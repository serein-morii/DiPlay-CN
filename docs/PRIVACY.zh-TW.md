# 隱私權與診斷

[繁體中文首頁](../README.zh-TW.md) · [報告匯出步驟](SETTINGS.zh-TW.md#匯出診斷報告與回報問題) · [英文原文](PRIVACY.md)

## 連線與本機資料

DiPlay 使用本機認證，透過 USB／Wi-Fi 直接連線 iPhone，不需要帳號、遠端認證服務或自動上傳診斷報告。iPhone 上的 CarPlay 應用程式有各自的網路與隱私行為。

車機會在應用程式儲存空間保存偏好設定、所選配對裝置、配對資料與有容量限制的診斷紀錄。認證及配對素材不納入 Android 備份。解除安裝會移除私有資料；匯出到下載資料夾的報告會保留，直到你自行刪除。

## 診斷報告

匯出由你主動操作。報告包含應用程式／裝置版本、顯示設定與協商、連線階段、Wi-Fi 頻段／頻道／狀態及解碼器恢復事件。開啟選用的方向盤按鍵服務時，報告也會列出該服務最近收到的實體按鍵（按鍵碼、掃描碼，以及 DiPlay 如何處理）；會輸入文字的按鍵只計數、不列出，也不記錄輸入裝置名稱。匯出器會過濾協定內容、含憑證的紀錄及常見識別資訊，但無法保證辨識所有廠商特有字串。公開分享前請自行檢查；GitHub 問題是公開的。

Android 9 以下儲存到 `Download/DiPlay` 時會要求儲存權限。若未允許、下載儲存空間不可用或檔案選擇器失效，會使用主要外部儲存的 `Android/data/<package>/files/diagnostic-reports/`；此備援不需要儲存權限。CN 正式套件是 `com.shihab.diplay.cn`；請以實際 APK 的套件名稱辨識 debug 建置。

若外部儲存也不可用，報告會存入應用程式私有空間。各備援位置保留最新八份匯出，解除安裝時會移除。確認訊息會顯示實際 TXT 路徑；較新 Android 的檔案管理器可能限制 `Android/data` 存取，可改用 DiPlay 的檢視或分享功能。

分享只授予所選報告的讀取權，沒有任何報告會自動傳送。在 Android 9 以下，具有儲存權限的其他應用程式可能讀取外部報告。

## 權限用途

- 麥克風：Siri 與通話。
- 藍牙／附近的裝置、Wi-Fi／位置：尋找裝置及建立連線。
- 本機 VPN：USB 網路連線，不提供遠端上網 VPN。
- 選用的使用狀況存取權：已驗證的 DiLink 5.1 儀表配置可用來跟隨主題與迷你地圖卡片的顯示狀態。此權限能讀取應用程式活動紀錄；DiPlay 在本機只處理四個原廠比亞迪儀表活動，紀錄推定的主題／可見狀態變化，不保留或上傳無關事件。自動模式需主動開啟，關閉即停止查詢。撤銷方式見[英文導航指南](BYD_NAVIGATION.md#dilink-51-theme-profile)。

## 更新及外部服務

DiPlay 開啟後不久及每天會檢查 GitHub 公開版本清單。請求的 User-Agent 包含 DiPlay 版本，不包含其他資料；GitHub 會看到車機的 IP 位址。只有你點選後才會下載或交由 Android 安裝，可在 **關於** 關閉背景檢查。

下載的更新會對照公開校驗值驗證，Android 10 以上也會複製到 `Download/DiPlay`。

靜態網站沒有分析追蹤程式或帳號。使用 GitHub Pages、GitHub 或 Telegram 時，適用各服務自身的隱私政策。
